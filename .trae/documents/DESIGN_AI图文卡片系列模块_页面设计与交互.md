# AI图文卡片系列模块：页面设计与交互说明（Desktop-first）

## 全局规范（适用于本模块所有页面）
### Layout
- 采用“顶部导航 + 居中内容容器”的混合布局：页面最大宽度 1200px，左右留白随窗口增大。
- 主内容区域使用 CSS Grid（卡片网格）+ Flex（工具条与表单行）。
- 断点：Desktop ≥ 1024；Tablet 768–1023（网格列数减少）；Mobile ≤ 767（抽屉/底部操作条）。

### Meta Information
- title：AI图文卡片系列 - {页面名}
- description：批量生成风格统一的图文卡片，支持进度反馈、失败重试与批量下载。
- Open Graph：og:title 同 title；og:image 使用系列封面或默认占位图。

### Global Styles（设计 Token）
- 背景：#0B1220（深色）/ 内容卡片：#111A2E
- 主色：#6D5EF7（Primary）/ 强调：#22C55E（Success）/ 警告：#F59E0B / 错误：#EF4444
- 字体：中文优先系统字体；标题 24/20/18；正文 14/16；数字与状态使用等宽可选。
- 圆角：卡片 14px，按钮 10px；阴影：elevation-1（轻）/ elevation-2（悬浮）。
- Button：Primary（填充）/ Secondary（描边）/ Ghost（透明）；Hover 提升亮度 + 阴影；Disabled 60% 不透明。
- Link：#A5B4FC，hover 下划线。

### 通用交互与状态
- Loading：骨架屏（列表/网格）+ 顶部轻量进度条（长耗时任务）。
- Empty：提供“创建系列/开始生成”主行动按钮与示例。
- Error：错误提示包含“人话描述 + 错误详情可展开 + 建议操作 + 重试入口”。
- Long Task：统一用“任务条（Job Bar）”组件：阶段标签、进度、预计剩余（可选）、后台运行提示。

## 页面 1：卡片系列列表页（/series）
### Page Structure
- 顶部：模块标题 + 主按钮“创建系列”。
- 中部：筛选工具条（搜索框、状态下拉、排序下拉）。
- 下部：系列卡片网格（Grid，Desktop 3 列，Tablet 2 列，Mobile 1 列）。

### Sections & Components
1. 顶部导航区
   - 左：面包屑（可选：工作台 / AI图文卡片系列）
   - 右：主按钮“创建系列”（Primary）
2. 筛选工具条（Sticky，滚动时吸顶）
   - 搜索：按名称/标签
   - 状态筛选：生成中/成功/部分失败/失败
   - 排序：最近更新/最近创建
3. 系列卡片（Series Card）
   - 封面缩略图（使用该系列第一张成功卡片，否则占位）
   - 标题、风格标签、目标数量
   - 状态角标：
     - generating：紫色脉冲点 + “生成中”
     - partial_failed：橙色 “部分失败”
     - failed：红色 “失败”
     - succeeded：绿色 “已完成”
   - 次要信息：最近更新时间、成功/失败计数
   - 点击整卡进入系列详情
4. 创建系列弹窗（Modal）
   - 字段：系列名称（必填）、风格模板（必选）、默认尺寸/版式（必选）、默认数量（1–100）
   - 校验：就地提示 + 禁用提交
   - 提交后：toast“创建成功”，自动跳转到系列详情

## 页面 2：系列详情与生成页（/series/:seriesId）
### Page Structure
- 顶部：系列标题区（标题、标签、状态）+ 右侧主行动（开始生成/重试失败/批量下载）。
- 左侧（Desktop）：生成配置表单（Card）；右侧：任务条 + 结果网格。
- Mobile：配置折叠为顶部折叠面板，结果与任务优先展示。

### Sections & Components
1. 系列标题区（Header）
   - 标题：系列名称
   - 标签：风格、尺寸/版式
   - 指标：目标数量、成功、失败、进行中
   - 主行动按钮逻辑：
     - idle：显示“开始生成”（Primary）
     - generating：显示“后台继续生成”（Ghost）+ “查看日志”（Secondary）
     - partial_failed：显示“重试失败项”（Primary）+ “批量下载成功项”（Secondary）
     - succeeded：显示“批量下载”（Primary）
2. 生成配置（Config Card）
   - 数量（Stepper）
   - 版式预设（Preset Chips + 预览缩略图）
   - 文案输入：
     - 模式切换：手动输入/批量粘贴
     - 批量粘贴支持按行拆分，提示“行数与数量不一致时的处理规则（截断/循环/提示）”
   - 生成前校验：必填、数量上限、敏感字符提示（仅提示不阻断可选）
3. 生成流程反馈（Job Bar + Timeline）
   - Job Bar：阶段（排队/文案/图片/合成/上传/完成）+ 总进度 done/total
   - Timeline（可折叠）：每阶段开始/结束时间、失败点位、错误详情（可复制）
   - 后台运行：允许你切换页面，返回后仍展示最新状态
4. 结果网格（Cards Grid）
   - Grid：Desktop 4 列，卡片比例锁定
   - 卡片项内容：缩略图/占位、编号、状态角标、操作菜单
   - 状态展示：
     - queued/generating_*：显示 shimmer 占位 + 文案“生成中…”
     - failed：显示错误 icon + “查看原因 / 重试”
     - succeeded：显示缩略图
   - 操作：点击进入预览；更多菜单：重试单张（失败态）、重新生成（成功态可选）、删除（可选）
5. 失败重试面板（Drawer/Modal）
   - 展示：失败数量、失败原因分组（如超时/内容不合规/模型错误）
   - 动作：重试失败项（Primary）、仅重试选中项、重新生成全部（Danger 二次确认）
6. 批量下载（Export）
   - 入口：按钮“批量下载”打开弹窗
   - 选择：全部/仅成功/自选（勾选网格项）
   - 提示：预计数量与体积（无法估算则提示“可能较大”）
   - 执行：显示打包进度条；完成后提供“下载”按钮与“复制链接”（可选）
   - 失败：显示错误原因 + “重试打包”

## 页面 3：卡片预览页（/series/:seriesId/cards/:cardId）
### Page Structure
- 左：大图预览（可缩放/适配容器）；右：信息与操作面板。
- Mobile：大图在上，操作面板在下（底部固定操作条）。

### Sections & Components
1. 顶部返回区
   - 返回“系列详情”
   - 显示：卡片编号 + 状态
2. 大图预览区
   - 成功态：展示高清图（渐进加载：先缩略后高清）
   - 生成中：展示占位骨架 + 阶段提示
   - 失败态：展示失败插画/占位 + 错误摘要
3. 文案与元信息
   - 文案字段：标题/正文（按你的实际字段）
   - 操作：一键复制（复制成功 toast）
4. 操作按钮
   - Primary：下载单张
   - Secondary：在系列中定位（跳回并高亮该卡片）
   - 失败态：Primary 改为“重试生成”

## 美观性增强要点（落地为 UI 规则）
- 统一卡片阴影与圆角，网格密度“紧凑但不拥挤”（网格 gap 16–20px）。
- 状态颜色与文案一致（成功绿/失败红/进行中紫），避免同一状态多套样式。
- 长耗时反馈“始终可见”：顶部 Job Bar + 可展开日志，减少用户焦虑。
- 结果优先：生成中也尽早把已完成卡片填入网格（增量可见）。
